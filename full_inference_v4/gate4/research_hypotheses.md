# 研究假设与验收

| 假设 | 可支持的证据 | 可削弱或证伪的证据 |
| --- | --- | --- |
| 小 Grid 增加空间并发机会 | 固定探针工作、资源差异及 GPU 时间线，QKV 与 Gate/Up 表现出可重复的区别 | 小 Grid 在相同控制下产生更大干扰或更少的有效窗口内工作 |
| NVFP4 的较大 CTA 限制同 SM 共驻 | 真实函数资源与保守的单 SM 必要约束出现冲突 | 对应的 CTA 级位置及时间证据证实共驻，需要复核模型和分配规则 |
| 主投影和探针类型共同决定竞争 | 正交选择 QKV/Gate-Up、FP32 Light/Heavy 和 BF16 MMA，光靠精度或 Grid 无法解释全部结果 | 固定工作量对照的效应全部落在重复噪声内 |
| 并发帮助真实推理 | 真实下游消费、验证同等负载下的无 Profiling 请求延迟或吞吐 | 联合窗口改善但请求无收益，或者辅助工作错过消费者截止时间 |

通过配对 CUDA Event 估计延迟干扰和联合完成收益。使用 GPU Kernel 区间检验时间重叠。实际 CTA 位置证据和端到端证据各自独立。
