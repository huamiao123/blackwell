# 生命周期、Stream与监督协议

完整请求窗口从预编码请求提交Engine到输出完成。联合窗口从A/B统一起点到两者完成；A请求完成不等于B完成。辅助任务尾部必须单列，不能按重叠时间比例假定已完成有效单位。

注入条件分Prefill/Decode/Lifecycle/Mixed，每个配置固定相同B工作量与实际消费者。若原始依赖只允许AB，BA仅用于独立Probe或依赖合法的任务；不能为凑齐BA而破坏真实数据依赖。真实有用任务若无合法BA必须标NOT_APPLICABLE并说明。

继承Gate2/3监督机制设计：授权窗口在任何GPU查询/模型导入前验证；检查外部计算进程和自动控制器；一个有限工作进程组、硬超时、冲突只结束自身进程；原始permit nonce不进入公开产物。当前没有修改历史监督器，也没有建立活GPU window。

Gate4准备CLI不会启动CUDA。未来接入时需新建Gate4专用worker/permit桥接，不能把旧Gate2配置中的gate编号随手更改或绕过其检查。控制Stream/Graph/辅助模块的生命周期需保持到join；异常清理也不得销毁在飞行对象。

如果Graph调度阻止外部Stream稳定共存，记录执行机制限制，不能据此推断硬件没有余量。当前未有真实集成测试。
