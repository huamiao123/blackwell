# 资源感知策略骨架与推进条件

当前策略默认disabled，缺少证据回到原始推理。它不是已经完成的通用调度算法。没有Gate4有效数据时，不使用SM Active、低Occupancy或Grid阈值直接推断可插入工作。

准入键包括设备UUID、精度、阶段、实际辅助函数/配置Hash、主Kernel family和workload manifest。必须是该有用任务自己的校准，不能将FP32 Probe低干扰直接推广到量化或KV转换。

设计中的部署条件：至少五配对Block、两独立进程、真实消费者/工作量/P0/时间线验证；A干扰95%区间上界≤5%，P95损失不超过初始预算，联合收益95%区间下界>1，普通并发对照已验证且新策略优于它，任务预估P95在截止时间内。缺字段/NaN/无限值/配置不符均回退。

这些是未来部署准入条件，不是说无需实验就知道收益。研究性校准需要单独审查的小试点；不能用“必须先证明策略优于普通并发”代替设计与测量本身。当前没有训练/拟合过资源竞争预测器，没有已验证阈值，没有有用工作执行路径。

后续若只人工挑一个窗口并发，报告为特定配置机制验证；只有跨形状决策、失配回退与相对普通并发优势可重复后，才讨论通用资源感知调度贡献。
